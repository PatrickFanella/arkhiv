15 A-Info issues from São Paulo, Brazil, dated 2011–2012 in their source titles.
Each issue has its own Internet Archive item, unlike the first bundled source.

Source: [A-Info collection](https://archive.org/details/a_info_zine). The bounded
discovery query is `collection:a_info_zine AND title:(2011 OR 2012)`; the complete
response returned 15 items. The [collection configuration](../../collections/a-info-zines.yaml)
sets a 25-item discovery cap, ten results per page and 64 HTTP requests per refresh.

Selection includes 15 PDFs and 15 OCR companions, totaling 98,015,146 bytes.
Each selected file has a recorded source checksum and no private flag. The batch
cap is 150 MiB, file cap 50 MiB and document cap 25; transfer concurrency stays
below two. Actual acquisition preserved all 30 selected assets. Private review, source-blocked reading and fresh independent restore passed; see [second-archive qualification](second-archive-qualification-20261003.md).

The collection uses a distinct name, purple accent and Portuguese/São Paulo
taxonomy. Source creators and catalog dates are absent; title dates are not silently
converted into precise catalog dates. Rights remain unknown because the source
does not provide a license statement. These unrestricted downloads establish access
evidence for private preservation, not approval for public redistribution.

Updates are enabled weekly with review-only policy. Newly found items and changed
files are queued; neither discoveries nor imported issues publish themselves. A
complete inventory includes all matching items within the configured cap. Pagination
or item-metadata failure cannot advance the baseline or infer removals. If the query
outgrows the cap, review the scope before extending it.
