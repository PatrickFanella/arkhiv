# Pilot public-access review — 2026-10-03

The proposed release is the 25-document private pilot, with 26 verified PDF variants.
The exact document/variant IDs and original hashes are recorded in
[the review manifest](../../collections/anarchist-zines-public-review.json).

Public URL: `https://arkhiv.subcult.tv`. Correction/removal contact:
`info@subcult.tv`. Originals remain preserved independently of access decisions.

Source downloads were unrestricted, but no explicit license for each complete
document was established in this review. The catalog source fields retain unknown
rights. Two texts contain scoped permission clues: *Varieties of Islamic Anarchism*
includes an author copyleft label with unstated terms, and *Fat Mutual Aid* names
permissions for particular components. These do not establish a blanket license
for the whole corpus. The owner explicitly approved public reading and downloads of this reviewed
corpus on 2026-10-03, with unknown rights labeled, source attribution and the
correction/removal contact, and no reuse license asserted.

Approved access policy: serve only individually approved variant hashes, retain
source/author attribution, display unknown rights without offering a reuse license,
and provide the correction/removal contact on document and About pages. A removal
decision revokes public catalog, search, cover, reader and download access while
retaining the original privately and recording the reason. Revoke before any
subsequent review; never overwrite an original to change access.
